# 饭搭子

> 今天吃什么？一个年轻、清爽的私人美食选择 Web App。

## 当前版本

首页视觉原型已经实现，包含：

- 六位可切换的“今日饭搭子”角色
- 常用状态选择
- 带状态权重的随机食物推荐
- 今日命运之选卡片
- 菜系灵感区域
- 桌面端与移动端响应式布局
- 使用 `localStorage` 保存角色选择和摇取次数

## 本地预览

项目没有构建依赖，可直接使用任意静态服务器：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 部署

全部资源使用相对路径，可以直接部署至 GitHub Pages 或其他静态托管服务。
